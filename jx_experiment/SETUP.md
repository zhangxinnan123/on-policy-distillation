# Environment Setup

## 1. Clone and checkout

```bash
git clone https://github.com/zhangxinnan123/on-policy-distillation.git
cd on-policy-distillation
git checkout zxn-dev
```

## 2. Install environment

```bash
bash install_env.sh
```

## 3. Download dataset

Edit `get_dataset.sh` to set the data path, then run:

```bash
bash get_dataset.sh
```
